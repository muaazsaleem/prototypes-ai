# Prompt

```text
Extract the sentiment and key entities from this customer review: 'The new smartphone is amazing, the camera quality is top-notch but the battery life is a bit disappointing. I love the design though!'
Output only a JSON object with the keys 'sentiment' and 'entities'. 'sentiment' should be a string (Positive, Negative, or Mixed). 'entities' should be a list of strings.
```
